# Hermes Agent — Branding-Seiten

Statische Seiten, die als Google-OAuth-Branding hinterlegt werden:

* `index.html` — Startseite der Anwendung
* `privacy.html` — Datenschutzerklärung

Sie beschreiben den privat betriebenen Automatisierungsagenten und wie er auf
Google-Nutzerdaten zugreift. Es läuft nichts dahinter — reines HTML.
